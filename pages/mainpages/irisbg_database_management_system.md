# IrisBG Database Management System

### Basic Information

UBC Botanical Garden plant accession data is managed using IrisBG database software. IrisBG is a collections management system used by more than 180 botanical gardens, arboreta, herbaria, and private estates around the world. Tutorials and user information are available online at [irisbg.com](https://www.irisbg.com/).  

There are two main ways to learn about using IrisBG:
>-- [IrisBG video tutorial and interactive training courses](https://www.irisbg.com/tutorial-p.aspx). (Official tutorials) \
>-- [The Botanical Software Youtube channel](https://www.youtube.com/user/botanicalsoftware/videos). (Additional training and Q&A)

To learn more about how to navigate IrisBG resources see Appendix: IrisBG online tutorials.

---

The software also has a built-in Help menu that can be accessed from the Help tab in the top bar (Help > Reference guide...) 

<img src="../figures/help_tab.png" alt="the help tab dropdown in IrisBG" width="600"/>\

The reference guide is an introduction to the essentials of the system and assumes that the user has basic computer skills and knowledge of collection management. On the left-hand side of the main window, you will find the navigation bar which is organized by topic. Above these topics is a search tab that can be selected to perform keyword searches. The resources in the reference guide can be information-dense but are invaluable when working with IrisBG in depth.
