# Taxonomy

Taxonomy information is created and maintained by the Accessions Technician or other users with the required privileges. Check with the informatics manager for user privilege. The [Taxa](/UBCBG-Plant-Records-Manual/taxa/) section in IrisBG allows users to manage the nomenclature, descriptions, images, and references of any taxon.
