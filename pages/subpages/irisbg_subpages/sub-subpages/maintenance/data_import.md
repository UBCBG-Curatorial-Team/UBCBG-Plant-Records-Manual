## Bulk Contact Creation or Editing
[Contacts](/UBCBG-Plant-Records-Manual/contacts/) (donors) can be imported or edited using the data import tool. The formatting of these sheets is specific and the error messages listed by IrisBG are not particularly descriptive. This section hopes to aid in the understanding and execution of contact data importation.

**The spreadsheet format for creating new contacts is, at its simplest:**

|ConCode |ConName |ConCountryCode |ConDonorTypeCode |
|------|------|------|------|
|EXAMPLE1|This is an example |CAN|B|
|EXAMPLE2|And another |USA|I|
|EXAMPLE3|Yet another |DEU|R|

> *The header names must **exactly** match what is shown here*

`ConCode` = the contact code (absolutely required by IrisBG) 

`ConName` = the contact name (absolutely required by IrisBG) 

`ConCountryCode` =  the country code in 3 letter (ISO 3166-1 alpha-3) format 

`ConDonorTypeCode` = the single-letter contact type code that can be found in IrisBG under Definitions > Code lists > Donor type. They are also listed below, but in the case that this list is outdated, see IrisBG. 
>-- B – Botanical garden or arboretum <br>
>-- D – Display or estate garden <br>
>-- E – Expedition <br>
>-- G – Gene bank <br>
>-- H – Horticultural association or garden club <br>
>-- I – Individual <br>
>-- M – Municipal department <br>
>-- N – Nursery or commercial <br>
>-- O – Other <br>
>-- R – Research institution <br>
>-- S – Staff of UBCBG <br>
>-- U – University department

While these four fields are the absolute minimum that should be included, additional information can be added by creating additional columns in the spreadsheet. The relevant column headers can be found in the Reference Guide. To navigate to this page, go to `Help >  Reference Guide > Usage > Data import files`, then scroll down to the "Contact" table (somewhat near the bottom of the list).  

To import the data, go `Maintenance > Data import` and then `Open file with data to import` (folder icon with arrow, at top). Navigate to your data folder and open. Upon loading the file, preview the data in the spreadsheet that is shown in IrisBG before pressing `Accept`.

**The spreadsheet format for updating contacts is, at its simplest:**

|Action|ConID|ConCode|
|--------|---------|--------|
|U|1|EXAMPLE1|
|U|2|EXAMPLE2|
|U|3|EXAMPLE3|

> *The header names must **exactly** match what is shown here*

`Action` = what is being done with this data. 'U' stands for "Update" and indicates that these contact already exist. 

`ConID` = the unique identification number assigned to each contact (required, can be generated by Cont01 report). ***Must match existing data in IrisBG.***

`ConCode` = the contact code *(absolutely required by IrisBG).*

To change information about a contact, add columns to the spreadsheet, following the field names in the Reference Guide (see the data import [contact creation section](/UBCBG-Plant-Records-Manual/data-import/#:~:text=The%20relevant%20column%20headers%20can%20be%20found%20in%20the%20Reference%20Guide)). Every field can be modified, **except for `Action` and `ConID`.**

To import the data, follow the instructions in the data import contact creation section above. The action column should say "Update" if everything has been done correctly.
