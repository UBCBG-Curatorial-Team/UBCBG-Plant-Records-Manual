# Request Label Scenarios

|Scenario|Notes|
|-|-|
|New accession with items |Usually nursery item labels will be requested first; if the material is going to be planted without going to the nursery, planting item labels will be requested. |
|A nursery item is ready for planting (i.e. from a nursery item to 1 or multiple planting items)  |Nursery labels and planting labels are not interchangeable. Planting labels must be requested per planting item since the item numbers are different on each item. |
|New planting items  |Planting item label request for new items that are a result of division, propagation, splitting a multi-individual item, or other scenarios that create new planting items. |
|Accession that has taxon name change (identification changed, or taxonomic update) |Applies to accessions that have existing planting items; all of the existing items need a new label. |
|Existing planting items that are moved or located in a different bed (due to bed split, error correction, or other changes)  |Applies to label types that have bed codes indicated on labels. If without bed code printed (e.g. Labels in the Asian Garden), the old label will be moved with the plant. |
|Lost/damaged/illegible labels  ||
|Changes to the info displayed on the label |e.g. fix an accession number, accession item number, collection number, typo and etc. |
